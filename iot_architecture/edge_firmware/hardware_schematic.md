# FlowJeep Paratransit Edge Node: Hardware Schematic & Pinout

## System Architecture Overview
The FlowJeep Edge Unit integrates an **ESP32-S3** microcontroller as the edge processing unit with four primary hardware peripherals:
1. **SIM7600E-H 4G LTE Modem**: High-speed cellular telemetry & MQTT uplink.
2. **ATGM336H / NEO-8M GNSS Receiver**: Accurate 10Hz position, speed, and heading.
3. **Dual E18-D80NK Adjustable Optical Infrared Sensors**: Directional passenger counting state machine.
4. **OV2640 DVP Camera Module**: Optical verification of doorway boarding/alighting events.
5. **Automotive Power Regulator**: DC-DC Buck converter converting 12V/24V vehicle battery to stable 5.0V @ 3.5A with TVS diode surge suppression.

## 2. Dual E18-D80NK Sensor Placement & Finite State Machine

```
   [ OUTSIDE JEEPNEY ENTRY STEP ]
                  │
      ┌───────────▼───────────┐
      │  Sensor A (Outer Beam) │  <-- Beam across outer threshold (GPIO 4)
      └───────────┬───────────┘
                  │   ~ 18 cm - 25 cm physical separation
      ┌───────────▼───────────┐
      │  Sensor B (Inner Beam) │  <-- Beam across inner cabin step (GPIO 5)
      └───────────┬───────────┘
                  │
      [ INSIDE JEEPNEY CABIN ]
```

### State Sequence:
- **Boarding (Entering)**:
  1. Sensor A obstructed (`LOW`) -> State `BEAM_A_FIRST`
  2. Sensor B obstructed (`LOW`) within 1.8s timeout -> **Boarding event triggered (+1 count)**
  3. Camera triggers snapshot frame for CV confirmation.
  4. Both sensors clear -> State `IDLE`.
- **Alighting (Exiting)**:
  1. Sensor B obstructed (`LOW`) -> State `BEAM_B_FIRST`
  2. Sensor A obstructed (`LOW`) within 1.8s timeout -> **Alighting event triggered (-1 count)**
  3. Camera triggers snapshot frame for CV confirmation.
  4. Both sensors clear -> State `IDLE`.
- **Cancellations**:
  - If a passenger hovers or reverses before triggering the second sensor, a 1800ms timer resets state to `IDLE` without incrementing or decrementing.

## 3. Automotive Power Circuitry (12V-24V Alternator Protection)
Jeepney electrical systems experience heavy load dumping and voltage spikes up to 40V when the starter motor or alternator disengages.
The power conditioning board features:
- **TVS Diode (SMBJ28A)**: Clamps inductive spikes above 28V.
- **PTC Resettable Fuse (3A)**: Protects against dead shorts.
- **Schottky Diode (SS34)**: Reverse polarity protection against inverted battery connections.
- **XL4015 / TPS5430 Buck Converter**: High-efficiency step-down to 5.0V with <25mV ripple.
- **Bulk Capacitance**: 1000µF Low-ESR electrolytic capacitor directly across the SIM7600 VBAT rail to handle 2.0A LTE transmission bursts.
